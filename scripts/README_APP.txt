ATLAS Beacon 0.8.0
==================

Double-click "ATLAS Beacon.exe" to open the native Windows application.
No browser or local web server is started by the desktop app.
Select an asset in Library and press Space for a temporary preview.
Use Beacon Desk on Overview for durable questions and plain-English replies.
Edit contextual metadata in Library; verified technical facts remain locked.
Managed moves are destination-bounded, checksum-verified, and audited.

Runtime data:
C:\ProgramData\ATLAS\Beacon\

This build does not watch or index J:\ and does not alter original media.
